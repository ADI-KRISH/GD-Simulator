# intend to use.

#   ./.venv/Scripts/python.exe -m pip install -r services/requirements-llm.txt
#
# Then in .env, pick one:
#   LLM_PROVIDER=anthropic   LLM_MODEL=claude-opus-5   LLM_API_KEY=sk-ant-...
#   LLM_PROVIDER=openai      LLM_MODEL=gpt-4o-mini     LLM_API_KEY=sk-...
#
# Both sit behind services/llm/. No agent, prompt, aggregator or contract
# differs between them.
